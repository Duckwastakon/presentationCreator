## Overviewing

Prestyly is a presentation creation website made for people who need a presentation done in as little as 5 minutes. For any situation of having or wanting to make a unexpected presentation.
The main idea is speed. Allowing 
Then after finishing the design the website allows the user to export their made project to a powerpoint file, to be then able to share it, or let others edit it in other software.
